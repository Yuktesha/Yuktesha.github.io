# 🚀 Jason Transformer (v2.1 Stable)

**Jason Transformer** 是一款純前端、無後端依賴的 **通用型 JSON 視覺化轉檔工作台**。

它能將結構複雜、層級深奧、對人類極不友善的 JSON 陣列或巢狀資料，在一毫秒內自動扁平化（Auto-Flatten），並自由變身為三種極致直覺的檢視型態。同時，它也是一個強大的轉檔工具，支援線上自訂表頭，並一鍵匯出為符合微軟 Excel 標準編碼（防亂碼）的 `.csv` 試算表。

---

## ✨ 核心特色與四大功能

1. **📁 智能拖曳與本地解析 (Drag & Drop)**
   - 介面提供極簡的虛線拖曳區，支援直接將 JSON 檔案拖曳進網頁。
   - 所有資料均在瀏覽器記憶體內進行純前端解析，**資料絕不上傳任何伺服器**，保障最高隱私。
2. **📊 自適應表格檢視 (Excel Grid View)**
   - 採用 `table-layout: auto` 技術，表格寬度能根據內容長短自動進行完美的彈性分配。
   - 針對固定長度欄位（如回合、出題者）強制進行不換行防禦（`nowrap`），將空間優雅地留給大量文字對白。
   - 凍結表頭（Sticky Header）設計，在大量數據向下滾動時，欄位標頭依然穩穩固定在頂端。
3. **🧱 獨創單一磚聚焦與鍵盤導航 (Single Card View)**
   - 提供「一次只看一筆資料」的專注大字磚檢視。
   - **全域快捷鍵支援**：切換到單一磚模式後，雙手無需離開鍵盤，輕敲 **左方向鍵 `←`** 或 **右方向鍵 `→`** 即可如簡報般流暢翻頁。
   - 底部設有極簡導航區，可直接鍵入指定項次並按 `Enter` 瞬間跳轉。
4. **📥 線上更名與標準試算表下載 (Online Header Renamer & Export)**
   - 表格最上方的英文鍵值（Keys）表頭，**直接呈現為可即時編輯的文字輸入框**。
   - 使用者可以直接在網頁上將原始的英文欄位改寫成自己看得懂的文字（例如把 `word` 改為 `詞彙`）。
   - 點擊下載時，轉檔引擎會即時記憶最新欄位，並自動加入 **`BOM (Byte Order Mark)` 編碼保護**，下載後的 CSV 檔案用微軟 Excel 直接雙擊打開**絕對不會變成亂碼**。

## 🛠️ 技術疊代與開發歷程

本專案的開發過程是一場充滿挑戰與趣味的 **Vibe Coding** 經典實踐，歷經了五個核心版本的打磨與修正：

*   **v1.0 - 專案雛形（量身訂做時期）**
    最初本工具是為了視覺化閱讀「字戀 (WordChain) - 紀曉嵐與李白 578 回合的成語相聲對戰日誌」而設計。在這個階段，我們初步落實了將巢狀 JSON 轉為多欄卡片牆與死板表格的排版，但所有欄位名稱都是硬編碼（Hardcoded）在腳本裡的。
*   **v1.2 - 防禦優化與上傳功能建立**
    在嘗試打包成單頁應用（SPA）時，遭遇了 AI 平台單次輸出字數限制的「斷頭台截斷機制」。為了解決程式碼行尾被硬生生切斷、等號碎裂導致讀檔腳本失效的問題，我們將程式碼進行了嚴格的長度限縮與垂直拆列，並在此版本完美啟動了本地拖曳讀檔機制（`FileReader`）。
*   **v1.4 & v1.5 - 單一磚定義修正與自適應表格**
    在此階段，使用者對「單一磚」做出了最精確的產品定義：一次只看一筆，且必須具備跳轉與前後導航。我們在此版本成功加入了全域鍵盤方向鍵監聽器。隨後，為了解決文字換行過碎的痛點，引進了 CSS 表格自適應與 `white-space: nowrap` 類別，大幅提升了表格欄寬的平衡感。
*   **v2.0 - 通用旗艦版的靈魂飛躍**
    使用者提出了一個極具遠見的產品演進方向：「不介意 JSON 原始的英文欄位名稱，但希望能在網頁上直接打字修改表頭，或下載後再改。」這讓專案直接跳脫了特定格式的束縛。我們加入了**巢狀自動扁平化（Auto-Flatten）演算法**，不論丟入什麼 JSON 檔案，都能自動萃取不重複的鍵值，並將表頭轉化為可即時打字改名的輸入框，讓下載的 CSV 完美記憶使用者客製化的文字。
*   **v2.1 - 終極拆解與拼圖復活**
    在邁向通用旗艦版時，由於陣列高階語法（`map`/`forEach`）與多重迴圈導致代碼總長度再次觸發平台截斷。我們最終決定放棄高階糖衣語法，將整套 App 的架構打碎為三個乾淨的代碼片段。由使用者在本地環境以「分段組裝法」手動拼接，並同步移除了外層容器的固定高度限制（`max-height`），將滾動條高度自然释放，宣告專案完美完工！

## 🌐 部署方式

本專案為 **100% 純前端靜態網頁**，發布極其簡單：
1. 準備好本地組裝完成的 `index.html` 檔案。
2. 透過 **Google Antigravity Agent** 或手動將其上傳至 GitHub 儲存庫。
3. 開啟儲存庫的 **GitHub Pages** 功能，即可將其轉化為全世界皆可隨時存取的線上通用工具！
